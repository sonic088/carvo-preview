4. قواعد الربط المقفولة

  • ERP: Uploader → Seller API → staging → contrôle → approbation humaine → Publisher → catalogue؛ بلا SQL مباشر في platform/store.
  • Commandes: قراءة ops.order_ops + ops.order_lines + ops.parcels؛ بلا grant commerce لـ app_read.
  • تبديل حالة الطلبية عبر commerce internal endpoint، ماشي كتابة مباشرة في store.
  • زر visibilité يتنحّى؛ كل rayons ظاهرين حسب D-030. قرارات relevé تبقى «à venir» للقراءة.
  • JWT متحقق منه، actor لكل transaction، هواتف مخبّية، NULL يبقى مجهول، وsource + computed_at لكل نتيجة.
  • ما كاين حتى نشر prod بلا موافقة المالك.
